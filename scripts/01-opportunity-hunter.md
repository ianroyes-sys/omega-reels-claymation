## Caption

300 applications. 1 reply. "Someone more aligned." 💀

So Omega built me a job hunter and I open-sourced it:

1. It pulls entry-level openings from Greenhouse, Ashby, Lever and the SimplifyJobs lists
2. It kills duplicates, so you never apply to the same job twice
3. One résumé file builds every version (tech, finance, ops). Over one page and the build fails
4. Claude Code agents fill the applications in a real browser. Nothing counts as sent without a screenshot and a confirmation

The catch: it never invents facts, never pays fees, never enters your SSN, and never solves CAPTCHAs. A file called STOP freezes everything. Follow-ups get drafted, never sent. You hit send.

Needs Claude Code and Python. Free and open source on GitHub.

Comment HUNT and I'll send you the repo.
